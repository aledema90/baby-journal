# Screenshots

Drop the app screenshots here using these exact filenames so the main
[`README`](../../README.md) picks them up automatically:

| Filename | Screen | Route |
| --- | --- | --- |
| `today.png` | Daily log (feedings, sleep, diapers) | `/` |
| `calendar.png` | Month calendar with activity dots | `/calendar` |
| `weight.png` | Weight chart over time | `/weight` |
| `drops.png` | Supplements / vitamin drops | `/gocce` |
| `family.png` | Co-parent sharing | `/family` |
| `auth.png` | Login screen | `/auth` |

**Tips**
- Use a phone-width viewport (~390 px) — the app is a portrait PWA.
- Prefer light, non-sensitive data if you ever make the repo public
  (e.g. a "Demo Baby" rather than real records).
- PNG, roughly 390×844, keeps the README crisp without bloating the repo.
