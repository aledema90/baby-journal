# Baby Journal

A small, friendly app to log and share your baby's daily care — feedings, sleep,
diapers, and milestones — with a co-parent.

Built with React, TypeScript, Vite, Tailwind CSS, shadcn/ui, and Supabase.

## Getting started

```bash
# install dependencies
npm install

# copy environment variables and fill them in
cp .env.example .env

# start the dev server
npm run dev
```

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the Vite dev server |
| `npm run build` | Production build |
| `npm run preview` | Preview the production build |
| `npm run lint` | Run ESLint |
| `npm run test` | Run the test suite once (Vitest) |
